# Повторная проверка импорта — 08.09.2026

Этот документ заменяет прежний план проверки от 07.09.2026. Production читался
через pg_dump и SELECT списка миграций; импорт, изменение схемы, push и перезапуск
production не выполнялись. Подтверждены обе миграции 0011 и merge 0012.

## Актуальная структура

CollegeGroup хранит поток: ИИ1, ИИ2, Кибер1, Кибер2, Кибер3, Кибер4.
Каждому принадлежат четыре Group через Group.main_group: Кибер, Английский,
Японский, Пайтон. Имена предметных групп сохраняются из источника (`<поток>-<предмет>`).
StudentProfile.group — предметная группа `<поток>-Кибер`, не CollegeGroup.
Все четыре предмета, включая Кибер, входят в StudentProfile.college_groups.

Импортёр дополнен созданием/поиском CollegeGroup, проверкой main_group существующих
Group и блокировкой существующих предметных связей с другим потоком. CollegeGroup
включена в блокировку таблиц при применении. Существующие связи не переносятся
и не удаляются автоматически. Правила телефонов, оценок, архива и идемпотентности
сохранены. Новая миграция не нужна.

API проверяет единый main_group предметных связей, но допускает любой назначенный
предмет в StudentProfile.group. Форма StudentsPage отправляет первым предметом
college_groups[0]. Поэтому последующее редактирование через UI может изменить
основной предмет: правило «Кибер» гарантируется этим импортом, но не всем API/UI.
UI требует курс, модель допускает пустой; курс и имя родителя не выдумываются.

Из 103 студентов один не импортируется из-за неподходящей формы телефона:
после согласованной очистки остаются 11 цифр, первая не 7, знак + отсутствует.
Исправление не угадывалось. Приватный отчёт с логином, ФИО, потоком, исходным
номером и точными JSONPath всех его вхождений:
`/tmp/college-review-20260908/invalid-phone.json`, права 0600, каталог 0700.
Нужен проверенный номер через приватное решение parent_phone и новый dry-run.
Полный состав после разрешения этой зависимости — 103 профиля / 412 связей;
количество оценок требует пересчёта, а не механической прибавки всех ячеек.

Все 4949 ячеек архивируются. Из них 2434 создают LessonRecord, 474 являются
пустыми/дефисами и не создают оценок, 2041 остаются только в архиве.
В последних 607 зависят от неразрешённых данных: 450 без даты, 121 непустая
без подтверждённой личности, 36 у заблокированного студента; 1434 содержат
неподдерживаемые результаты. Всего без личности 165 ячеек, включая 44 пустых.
15 строк списка без журнала относятся к 8 разным студентам: отсутствие строки
не считается пропуском. Даты и личности не подставляются по предположению.
Архивные строки неизменяемы; позднее разрешение их зависимостей потребует
отдельной проверенной процедуры, повторный импорт их скрыто не обновляет.
